Vice Guide — an offline tracker and guide for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Tick off your progress (saved in your browser), filter by story/missable/collectibles/activities and grade, hide story spoilers, follow a roadmap to the platinum, and read a cited guide for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Everything loads from files under `app/`, so it also works with the network off: open `app/index.html` directly or serve the folder with any static server.
